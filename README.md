# Family & Friends 1 — Unit 1 互动小游戏

## 打开方法

双击 `index.html` 即可开始。推荐使用 Chrome、Edge 或 Safari。

游戏不需要联网，也不需要安装任何软件。英文朗读使用浏览器自带语音，因此不同电脑上的声音可能略有不同。

## 学习内容

1. 动画微课：六幕原创讲解，覆盖本单元知识地图。
2. 词汇实验室：11 个学校用品词汇的图片、读音、中文和例句。
3. 神奇问答机：练习 `What's this? — It's a ...`。
4. 动作反应赛：练习 `Open / Close the book / door / window`。
5. 声音侦探：Aa–Dd、字母名称及单词首音。
6. 终极挑战：10 道随机综合题。

## 陪学建议

- 每次学习 15–20 分钟，每次完成 1–2 站。
- 先让孩子听，再鼓励孩子大声跟读。
- 答错时先点击喇叭重听，不急着直接告诉答案。
- 首页星星和学习进度会自动保存在当前浏览器中。
- 点击右上角“重新开始”可清除全部进度。

## 文件说明

- `index.html`：游戏入口
- `styles.css`：页面视觉与动画
- `app.js`：题目、语音和学习进度逻辑
- `assets/foxy.png`：原创学习伙伴插画
